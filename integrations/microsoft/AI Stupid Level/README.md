# AI Stupid Level connector (Power Automate, Power Apps, Logic Apps, Copilot Studio)

The certification files for the AI Stupid Level connector, as a verified publisher:

- `apiDefinition.swagger.json`: Send a prompt, Preview the route, Get usage for this month, and the internal list of routing modes.
- `apiProperties.json`: the router key connection parameter, and a policy that sends it as `Authorization: Bearer <key>`.
- `icon.png`: 230 × 230 on the brand colour #1a5fd8.
- `intro.md`: the documentation page Microsoft publishes with the connector.

Every action has a Sandbox option (real routing, mock answer, nothing spent). Create the connector in a Power Platform environment with `paconn create` or the custom connector wizard, run the Solution Checker, then package and submit it in Partner Center ([verified publisher process](https://learn.microsoft.com/connectors/custom-connectors/submit-for-certification)).
